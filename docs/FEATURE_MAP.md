## Updating a row

Re-run that gate on a Mac. Copy the short SHA, CDHash, and board path into that row's Status. Leave the other rows alone. `RED` adds ` gate=<id> evidence="<grade.json evidence>"`. `UNGRADED` has no CDHash or board; it is for a surface no Mac run has scored.

## How to read a red row

Stage diagnostics (`stages.log`, `trace.py`) grade nothing. Read [qa/v0-diagnostics.md](qa/v0-diagnostics.md) for the first failure, then the gate definition in [qa/v0-grading.md](qa/v0-grading.md).
